## E. 判断词强度对照（写错就是学术不端风险）
| 证据强度 | 允许的动词 | 禁止 |
|---|---|---|
| 阻断/敲除/回补实验 | demonstrate, establish, show | — |
| 处理间显著差异 | indicate, show | prove |
| 相关分析 | be associated with, be correlated with | regulate, drive, determine |
| 单一时间点观测 | suggest, may reflect | confirm, demonstrate |
| 模型预测 | predict, project | demonstrate |
| 文献一致 | be consistent with, in line with | confirm |

中文同理：证明 > 表明 > 说明 > 提示 > 可能与……有关。**相关系数只能写"与……显著相关"，不能写"调控/决定/驱动"。**

## F. 旧式排版遗留（新版期刊已不用，一律改）

这一节是 v1.1 新增：不是"用得太多"，而是"这种写法本身已经被淘汰"。

### F1. 悬空图表引用

| 旧式 | 语料次数 | 新式 | 语料次数 |
|---|---|---|---|
| `××见图 1` / `见图1` | 4（0.09%） | `……（图 1）` | 148（3.3%） |
| `如图 7 所示` / `图7所示` | 15 / 9（0.43%） | `……（图 7）` | 同上 |
| `详见/参见图 n` | 0 | `……（图 n）` | 同上 |
| `see Fig. n` | 1（0.03%） | `… (Fig. n)` | 203（6.35%） |
| `are shown in Fig. n` | 9（0.28%） | `… (Fig. n)` | 同上 |
| `Fig. n shows …` | 0 | `… (Fig. n)` | 同上 |

改法：引用不是句子成分，是**括号里的定位符**，贴在被它支撑的那句陈述后面。
- ✗ `区位与空间本底见图 1。场址中心由…换算得到，为 106.5296°E、26.6499°N。`
- ✓ `场址中心由项目总平面图的高斯-克吕格坐标换算得到（图 1），为 106.5296°E、26.6499°N。`

### F2. 「就……而言」框架

| 旧式 | 语料次数 | 改法 |
|---|---|---|
| `就……而言 / 就……来说 / 就……来讲` | 7（0.16%） | 直接以该对象作主语 |
| `as for` | 2（0.06%） | 直陈 |
| `in terms of` | 7（0.22%） | for / in / 直陈 |
| `with respect to` | 5（0.16%） | 多数可删 |

- ✗ `就约束如何被内化而言，本案的规制强度接近该类地区的上限。`
- ✓ `本案的规制强度接近该类地区的上限。`
- ✗ `就收益如何被截留而言，三个层级都对应可登记的权利主体。`
- ✓ `三个层级（农房、集体资产、闲置空地）都对应可登记的权利主体。`

### F3. 正文冒号

| 场景 | 语料次数 | 改法 |
|---|---|---|
| 中文正文 `：` | 219 句（4.9%） | 逗号、分号或拆句 |
| 其中 `研究表明：A；B` | 30 | `研究表明，A；B` |
| 其中 `机制在于：…` / `分为2部分：…` | 部分 | 删冒号，直接接内容 |
| 英文正文 `: ` 引出分句 | 112 句（3.5%） | 逗号或拆句 |

例外（可保留）：图表题注、收稿日期/基金项目/作者简介/DOI/中图分类号、`EC：3.2.1.67` 这类编码、`1∶1` 这类比例、`DR5::GUS` 这类构建名。
